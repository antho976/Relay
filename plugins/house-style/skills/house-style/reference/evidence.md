# Evidence

The owner's own words behind the rules in `../SKILL.md`, with dates, quoted as written (typos
included). Read this before deciding a rule doesn't apply, and add to it when the owner makes a new
call. Sources: Relay, Avex and Tally session transcripts, Avex's `.claude/design/DECISIONS.md` and
`SETTLED.md`, Relay's `DESIGN.md` and agent memory.

## The look

- 2026-10-27, Relay main page: "make a professional version ... use the best practices keep the UI
  clean and good to look at try to match the UI of claude or t3code but in relay's style ... it
  should be black and one with at most a little bit of color."
- 2026-10-05, Tally: "update the UI to not be crowded, AI looking, full of rounded everywhere, more
  professional".
- 2026-10-05, Tally: "I don't like these big boxes, look at what I did for Avex".
- 2026-09-27, Avex settings: "it's dating and doesn't feel pro at all use the best design practices
  and make it feel like a professional app."
- 2026-09-27, Avex: "Overall I think you went too far on the round UI ... looks off when rounded."
  Then: "I'd rather not have rounded grey backdrop".
- 2026-10-08, Relay: "the dev and thread boxes looks too futuristic".
- 2026-10-17, Avex: "gallery stands out too much it's big, full of red etc".
- 2026-08-16, Avex: navy accent on near-black was "bland and lifeless", so the accent should have
  heat (Ember, then Red `#E23D3D` by default).

## Consistency

- 2026-10-08, Threads: "make sure the UI flows to both dev and thread are not seperate apps ... the
  UI needs to be alike not worlds different".
- 2026-10-17, Avex: "the settings look nice but too different from the rest".
- 2026-10-15, Relay: "they're not see through enough like in skills the instruction/project is perfect
  ... make everything have a rule so that it looks good". This became the Glass Rule.
- 2026-10-13, Relay board: "make it feel like the rest of the app ... it way too see through compared
  t other parts of the app".
- 2026-08-22, Avex: "I like the current design ... but something's wrong with it and I can't point
  what". The cause was small inconsistencies: ground, hero face, header style, radius, press response.
